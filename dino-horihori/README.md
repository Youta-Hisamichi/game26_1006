# 恐竜ほりほり

ハンマーで岩を掘ると恐竜が出てくる、ブラウザゲーム。`index.html` を開くだけで遊べます（ビルド不要）。

- 恐竜52種・レア度 N / R / SR / SSR / UR・図鑑コンプ対象
- 掘り方（回転方向・縦横・速さ・指を離す回数）で出やすい恐竜が変わる
- 一度出たクセ付き恐竜は10分間出ない（`localStorage` に保存）
- ゲーム画面の直下にシェアボタン

## 画像の差し替え

`game.js` の `GEMS` 各行の `img` に画像のURL（相対パス可、`data:` URIも可）を入れると、絵文字の代わりにその画像が表示されます。空のままなら `emoji` が使われます。シェア画像（canvas）では外部ファイルが読み込めない場合があるため、確実に出したいときは `data:` URI にしてください。

## 言語

右上の「EN / 日本語」ボタンで切り替えできます（選んだ言語はブラウザに保存）。文言は `game.js` 冒頭の `I18N`、恐竜の英語名は `ENG` にあります。
